3.1 Structure of the output directory

The results of the pipeline run will be saved in results/nfcore_rnaseq_processing_subsampled. The top-level folder structure is as follows:

.
├── bowtie2_salmon
├── fastqc
├── fq_lint
├── multiqc
├── pipeline_info
└── trimgalore
