# 2.5. Interpretation of RNAseq processing results using the multiQC report
The nf-core/rnaseq pipeline generates a multiQC report which consolidates all quality control (QC) metrics from the pipeline run.  
We will be analyzing the [multiQC report from processing the entire dataset](https://github.com/biosustain/dsp_transcriptomics_training/tree/main/results/multiqc_nfcore_rnaseq_full_dataset/multiQC_Ecoli_sac_ctrl_deDios_2025_full_dataset.html) - which we have done prior to this course - rather than the one generated in your test run.  

The multiQC reports summarizes important QC metrics from RNAseq data processing. This includes for example:
- Tabular overview of general statistics
- QC metrics from FastQC and other software tools, e.g. read quality scores, GC and adaptor content before and after read trimming, % duplication, % read alignmnt, etc
- PCA plot and Euclidean distance heatmap
- Versions of the software tools used (see the end of the report)


Please take a few minutes to inspect the multiQC report, list your observations and questions, and try to find explanations for the observations made. You can use the left panel for navigating the report. We will discuss your findings and questions afterwards.  

The three control samples are ```C1```, ```C2``` and ```C3```.  
The three saccharin treatment samples are ```sac1```, ```sac2```and ```sac3```.

For example, you could pay attention to the details of the following:
- How is are the per base quality scores?
    - see ```Sequence Quality Histograms before and after trimming```
- There is a maximum of 85% aligned reads? What could be the reason(s)?
    - see the ```General Statistics``` section
- Why is the percentage of aligned reads lower in C1 and C2 compared o all other samples?
    - see the ```General Statistics``` section, ```Per Sequence GC Content before and after trimming``` and ```Top overrepresented sequences```and ```Adaptor content```
- Insepct the duplication level of reads. What could duplication stem from and how to treat it?
    - see the ```General Statistics``` section, ```Fastq Sequence Counts```, ```Picard Mark duplicates```
- How do the samples cluster? (see ```BOWTIE2_SALMON DESeq2 PCA plot and sample similarity```)
